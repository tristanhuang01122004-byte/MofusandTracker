      🧍 Mon profil

      🤖 IA Claude (optionnel)

      Sans clé, l'IA estime les calories avec la base d'aliments de l'app (hors ligne). Avec une clé API Anthropic, Claude comprend n'importe quelle description (plats maison, restos…). La clé reste uniquement sur ton téléphone ; chaque calcul est facturé sur ton compte Anthropic (quelques centimes).

      📲 Importer mes pas avec Raccourcis

      Tu peux simplement taper tes pas sur l'accueil. Si tu préfères les importer depuis Santé :

      1. Ouvre l'app Raccourcis → onglet Raccourcis → touche +. Nomme-le MofuPas.
      2. Ajoute l'action « Rechercher des échantillons de santé » : Type = Nombre de pas, Date de début = est aujourd'hui, Regrouper par = Jour, Unité = pas.
      3. Ajoute l'action « Texte » : écris pas= puis insère la variable Échantillons de santé.
      4. Ajoute l'action « Copier dans le presse-papiers ».
      5. Lance le raccourci (▶︎), autorise l'accès à Santé la 1ʳᵉ fois.
      6. Dans MofuTrack, touche 📋 Importer dans la carte « Mes pas » → Coller.

      💾 Sauvegarde

      Tes données restent sur ton téléphone. Exporte-les de temps en temps (par exemple dans Fichiers ou iCloud Drive).
