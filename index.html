        📲 Importer mes pas avec Raccourcis

        1. Ouvre l'app Raccourcis (Shortcuts) → onglet Raccourcis → touche + en haut à droite. Nomme-le MofuPas.
        2. Touche Ajouter une action, cherche « Rechercher des échantillons de santé » et ajoute-la.
        3. Règle-la ainsi : Type = Nombre de pas, filtre Date de début = est aujourd'hui. Touche Afficher plus et mets Regrouper par = Jour et Unité = pas (le total du jour, sans doublon iPhone/Watch).
        4. (Optionnel) Ajoute une 2ᵉ action « Rechercher des échantillons de santé » avec Type = Énergie active, même filtre, Regrouper par = Jour, Unité = kcal.
        5. Ajoute l'action « Texte » et écris : pas= puis touche Variable → Échantillons de santé (le 1ᵉʳ). Si tu as fait l'étape 4, ajoute ;kcal= puis la variable du 2ᵉ Échantillons de santé.
          Exemple de résultat : pas=10432;kcal=385
        6. Ajoute l'action « Copier dans le presse-papiers » (elle prend le Texte automatiquement).
        7. (Optionnel) Ajoute « Afficher une notification » : Pas copiés, ouvre MofuTrack 🦈.
        8. Touche ▶︎ pour tester. La 1ʳᵉ fois, iOS te demande l'accès à Santé → Autoriser.
        9. Ouvre MofuTrack → accueil → 📋 Importer (raccourci) → touche Coller quand iOS le propose. C'est fait !

        ⚡ Encore plus rapide

        • Widget : ajoute le widget Raccourcis sur ton écran d'accueil et mets MofuPas à côté de l'icône MofuTrack.
        • Siri : dis « Dis Siri, MofuPas ».
        • Toucher le dos : Réglages → Accessibilité → Toucher → Toucher le dos → Toucher deux fois → MofuPas.
        • Automatique : Raccourcis → onglet Automatisation → + → Heure de la journée (ex. 21:30) → Exécuter immédiatement → choisis MofuPas. Tes pas seront copiés chaque soir, il te restera à toucher « Importer ».

        🧭 Variante « lien » (si tu utilises l'app dans Safari)

        Remplace les étapes 6-7 par l'action « URL » contenant (en insérant tes variables) puis l'action « Ouvrir les URL ». Les pas s'importent tout seuls à l'ouverture. ⚠️ Sur iPhone, l'app ajoutée à l'écran d'accueil a une mémoire séparée de Safari : cette variante n'écrit que dans la version Safari. Avec l'icône d'écran d'accueil, utilise le bouton « Importer ».

        💾 Sauvegarde

        Tes données restent sur ton téléphone. Exporte-les de temps en temps (par exemple dans Fichiers ou iCloud Drive).
